# Visite Sumaré Beta v0.1

Pacote inicial de dados para a primeira versão beta.

Arquivos:
- atrativos.json
- eventos.json
- empresas.json

Status padrão:
- em_revisao: entra no app para teste e pode ser removido/corrigido depois.
- ativo: true: aparece no app.
- destaque: true: pode aparecer na Home.
